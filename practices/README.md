# OpenSpec 个人实践

本目录用于积累使用 OpenSpec 时确认过的个人约束和工作习惯，作为以后整理、迁移工作方式的来源。

- 通用 Codex 工作约定仍在 AI-Mine 维护；这里只记录 OpenSpec / SDD 专项内容，不复制通用规则。
- 项目产生的 proposal、spec、design、tasks 等需求产物不是本目录的长期记录；是否保留由具体项目决定。
- 使用过程中发现的新做法先作为候选讨论，只有明确确认要形成长期习惯后，才写入本目录；不从临时任务自动推导全局规则。
- 未来如需 Codex Skill，应由本目录中的已确认约定形成独立、可迁移的工作流；不要直接修改 OpenSpec 自动生成的 Skill 来保存个人习惯。

目前尚未确认具体的 OpenSpec 流程规则。确认一条，再按其适用范围补充对应内容。
